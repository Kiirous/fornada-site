# Fornada — site

Página de apresentação do app Fornada, com a Política de Privacidade e os Termos de Uso. HTML e CSS puros, publicados pelo GitHub Pages.

- `index.html` — apresentação
- `privacidade.html` — Política de Privacidade (LGPD)
- `termos.html` — Termos de Uso
- `assets/` — estilo, ícone e capturas de tela (dados fictícios da demonstração)

Para ver no computador, abra `index.html` no navegador.
